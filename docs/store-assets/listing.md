## Description

```
Ahtapot is a cyber security extension that turns your browser into a cyber threat intelligence command center. Select any text on any webpage and instantly detect and analyze Indicators of Compromise (IOCs) — IP addresses, domains, URLs, file hashes, CVEs — across 11 professional threat intelligence sources, with AI-powered verdicts from Claude, Gemini and GPT.

🆕 NEW IN VERSION 3.1
• Türkiye SGB (National Cyber Security Directorate) threat feed — no API key required
• Streaming results: verdicts appear as each source answers
• Defang-aware detection: hxxps://, [.] and [at] notations are handled automatically
• Latest AI models with three cost tiers per provider
• Completely redesigned interface

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🛡️ 11 THREAT INTELLIGENCE SOURCES

VirusTotal, AlienVault OTX, AbuseIPDB, Shodan, GreyNoise, URLhaus, MalwareBazaar, Pulsedive, Scamalytics, ARIN and Türkiye SGB — malware scanning verdicts, IP reputation, malicious URL and phishing detection, network registration (WHOIS) and internet-exposure intelligence, queried in parallel with a single click.

Works out of the box: ARIN and Türkiye SGB need no API key — install and start analyzing immediately. The extension routes each query only to providers that support that IOC type, protecting your API rate limits.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🤖 AI-POWERED THREAT ANALYSIS

Let an AI model read every provider result and explain what it means:
• Claude (Anthropic), Gemini (Google) and GPT (OpenAI) — three model tiers per provider, from economy to frontier
• Summary — quick triage decisions in seconds
• Analysis — L1/L2 escalation support
• Detailed — full investigation with MITRE ATT&CK mapping
• Export results as Markdown or PNG for reports and documentation

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🔍 SMART IOC DETECTION

Automatically identifies IPv4/IPv6 addresses, domains, URLs, file hashes (MD5, SHA1, SHA256), email addresses, CVE numbers, and Bitcoin & Ethereum addresses — including defanged indicators exactly as they appear in threat reports and security advisories.

🔒 PRIVACY-FIRST ARCHITECTURE

• Your API keys are stored locally in your browser and sent only to the provider they belong to
• No backend, no account, zero data collection or tracking
• Direct HTTPS connections to official APIs only
• Open source and Content Security Policy compliant

⚡ BUILT FOR SECURITY WORKFLOWS

• Floating analyze button on text selection, right-click context menu
• Results stream in live with a clean side panel and tabbed sources
• Color-coded threat levels (Safe / Suspicious / Malicious / Unknown)

1. Install — ARIN and Türkiye SGB work instantly, no configuration
```
